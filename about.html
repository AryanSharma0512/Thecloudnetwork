About the club

A Purdue student club for people who like running technology.

The Cloud Network brings together students interested in homelabs, servers, Linux, networking, self-hosting, websites, and cloud infrastructure.

01 / Homelabs

What is a homelab?

A homelab is a place to learn infrastructure by running it yourself. It can be an old laptop, a tiny computer, or a virtual machine—no expensive rack required.

You can use it to host a website, experiment with Linux, run Docker containers, learn networking, or make a service available on the internet.

02 / How meetings work

Members can participate in several ways.

01

Workshops

Follow a beginner-friendly session on topics such as Linux, Git, Docker, websites, or networking.

02

Project time

Bring something you are building, join another member’s project, or ask for help getting an idea started.

03

Demos and troubleshooting

Show the group what worked, bring in something that did not, and work through the problem with other students.

03 / Getting started

New to this? That’s fine.

You do not need to be a CS major, own server hardware, or have experience with Linux, networking, Git, or Docker. A laptop is useful for hands-on sessions, but you do not need a rack full of equipment to take part.

Meetings are a place to ask basic questions, try unfamiliar tools, and get help from somebody who has probably run into the same error before.
