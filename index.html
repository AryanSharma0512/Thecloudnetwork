01 / What we do

Learn, build, and share what you figure out.

Members work on homelabs, websites, domains, networks, and self-hosted services. We run workshops, work on projects together, and help troubleshoot when a configuration does not behave the way it should.

Learn

Get started with Linux, servers, networking, Git, DNS, Docker, and web hosting.

Build

Bring a project, join another member’s project, or use a meeting to try an idea.

Share

Ask for help when something breaks, document the fix, and show the group what you made.

02 / What you can learn

Things we work on

01

Servers

Install Linux on spare hardware or a virtual machine, then learn how to administer it.

02

Self-hosting

Deploy a service with Docker and learn what it takes to keep it available.

03

Websites

Make a site available online, connect a domain, and understand DNS and hosting.

04

Networking

Work with addresses, ports, protocols, and the connections between devices and services.

05

Development tools

Use Git, GitHub, Docker Compose, and command-line tools on a real project.

06

Troubleshooting

Read logs, check configurations, and work out why a service stopped responding.

03 / Who can join

You can start here.

You do not need a homelab, a particular major, or previous experience. Come to a workshop or project night, follow along, and ask questions. If you already run your own services, bring what you are working on and compare notes with other members.

  • Bring a laptop if you have one
  • Ask when you get stuck
  • Work on your own project
  • Join a club project
  • Explain what you know
  • Document useful fixes
